# Правила разработки

## README — часть каждой пользовательской функции

Если изменение влияет на установку, настройку, доступ, безопасность или поведение
панели, тот же pull request должен обновлять `README.md` простым языком.

Хорошее описание отвечает на четыре вопроса:

1. Что изменилось для обычного пользователя?
2. Что ему нужно сделать?
3. Где найти результат или проверить работу?
4. Как безопасно отменить изменение или восстановить доступ?

Не следует ограничиваться названием технологии или внутренней реализацией. Команды
должны быть готовыми к копированию, а предупреждения — стоять до потенциально
опасного действия.

Английский `README.en.md` обновляется вместе с русским текстом до выпуска релиза.
